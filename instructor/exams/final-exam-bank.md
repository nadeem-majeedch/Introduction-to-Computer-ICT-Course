# Final Exam — Item Bank (Cumulative, emphasis Modules 5–8)

**Instructor-only.** Format guidance: 120 minutes. Structure: Mix A (concepts, Modules 5–8 weighted) + Mix B (problems) + one long scenario (C1). Modules 1–4 appear as *feeder* items (≈25% of marks), consistent with the published emphasis.

---

## Section A — Concept items

### Module 5 (heavy)
- A1. Truth table with simplification insight (`A AND NOT B` style). *(CLO-5)*
- A2. NAND universality: build NOT/AND/OR from NANDs. *(CLO-5)*

## Section B — Problems

- B1. Truth table for a four-variable expression; mark the XOR-discriminating row. *(CLO-5)*
- B2. Build the half adder output table; extend to full adder for a given input triple. *(CLO-5)*
- B3. Spreadsheet design: write the nested IF + absolute-reference formula set for a grading sheet. *(CLO-6)*

## Section C — Long scenario (choose one of two variants)

- C1-variant 1. "Phishing-led ransomware at a small business": incident ordering, layer autopsy, backup post-mortem (3-2-1 mapping), policy rewrite with role assignments. *(CLO-10, CLO-3 feeder)*
- C1-variant 2. "AI tool adopted by a student services office": data-use questions, bias risk in its outputs, verification workflow, disclosure policy for staff use. *(CLO-10, CLO-8 feeder)*

## Marking scheme guidance

- Scenario: credit *ordering and rationale*; lists without rationale earn half.
- B5: standard shapes required (oval/rect/diamond/arrows); every branch drawn — the diamond honesty is the discriminator.
- Long scenario: rubric per variant — diagnosis (30%), ordered response (30%), prevention/policy (25%), communication quality (15%).
