# Midterm Exam — Item Bank (Modules 1–4)

**Instructor-only.** Coverage: L01–L16. Format guidance: 90 minutes; Mix A (concept) + Mix B (worked problems) + one mini-scenario. Assemble the paper by drawing across all four modules; every CLO-1..4 must appear at least twice.

---

## Section A — Concept items (short answer)

### Module 1
- A1. Define a computer with the four-part definition; classify three given devices against it. *(CLO-1)*
- A2. Given a timeline card set, order five milestones and state one causal link. *(CLO-1)*
- A3. Classify four computers by scale/purpose; justify the two hardest. *(CLO-1)*
- A4. Digital divide: name the three layers; one policy per layer. *(CLO-1/CLO-10)*

### Module 2
- A5. Draw the von Neumann organization; label buses. *(CLO-2)*
- A6. Explain why the stored-program concept changed computing. *(CLO-2)*
- A7. Rank the memory hierarchy; justify with locality. *(CLO-2)*
- A8. RAID vs backup: a scenario asks which survives which failure. *(CLO-2)*

### Module 3
- A9. Place five software artefacts in the stack; justify the two trickiest. *(CLO-3)*
- A10. Boot sequence ordering with one "which stage failed?" diagnosis. *(CLO-3)*
- A11. Given a path scenario, write absolute and relative paths. *(CLO-3)*
- A12. Update priority: the known-vulnerability mechanism. *(CLO-3)*

### Module 4
- A13. Why base 2? The hardware-economics argument. *(CLO-4)*
- A14. ASCII/Unicode/UTF-8 relationship; identify a mojibake pattern. *(CLO-4)*
- A15. Lossy vs lossless: match four media types to modes with reasons. *(CLO-4)*
- A16. Two's complement: why hardware prefers it (the addition argument). *(CLO-4)*

## Section B — Worked problems

- B1. Convert (show method): decimal 200 → binary → hex; hex `0x2F` → decimal; octal `144₈` → decimal. *(CLO-4)*
- B2. Two's complement: encode −45; decode `1011 0110`; compute 100+50 in 8-bit signed and name the phenomenon. *(CLO-4)*
- B3. Truth table for a three-variable expression with intermediate columns required. *(CLO-5 — see note)*
- B4. Memory-hierarchy scenario: given workload + prices, allocate a budget and justify. *(CLO-2)*

> **Note:** CLO-5 (logic) belongs to Modules 5–8, examined in the final. B3 is included as a *stretch* item worth bonus only, or omit; do not count it toward the core.

## Section C — Mini-scenario

- C1. "A small office: slow PC with 4 GB RAM swapping, HDD at 92% full, no backups, updates disabled." Diagnose the three most consequential problems, order fixes by impact, and write the 3-2-1 plan for their data. *(CLO-2, CLO-3)*

## Marking scheme guidance

- Method marks for all conversions (correct answer, no method = half).
- Scenario items: credit the *ordering rationale*, not the fix list.
- Publish the coverage map (this table) minus this line and the notes to students; items themselves are not published.
