# Delivery Guide — Timing, Activities, Checklists

Companion to the eight module deck files. This guide carries the cross-course policy; decks carry per-lecture specifics.

## 1. Timing policy (how the 2 hours are built)

- **Run sheets are contracts, not scripts.** Each deck's run sheet allocates 120 minutes across blocks with an explicit buffer (6–22 min). Never schedule content into the buffer.
- **Per-slide targets** (`[~m]` in notes) sum to the block time, not the whole hour — slippage within a block is absorbed by trimming *discussion*, never the activity or the exit ticket.
- **Protected segments (never cut):** the lecture's main activity, the quick check, the exit ticket. If time collapses, cut body slides — the lecture page carries what the deck compresses.
- **Session rhythm:** opening hook ≤ 10 min · concept blocks ≤ 25 min before a switch (question, demo, or activity) · last 15 min always summary + exit ticket.
- **Two-hour endurance:** the mid-lecture activity is placed at the energy dip (~60–75 min mark) in every deck — do not move it earlier.

## 2. Activity instructions (the seven formats used across the decks)

| Format | How to run | Decks using it |
|---|---|---|
| **Think-pair-share** | 1 min silent think → 2 min pair → pairs report one sentence; instructor boards the range, then resolves. | L01 boundary cases, L17 policy, L22 journey |
| **Short concept check** | Individual write (3 questions) → pair-compare → instructor resolves with the module guide's answers. Timed 10–12 min. | Every lecture (the "Quick check" slide) |
| **Guided demonstration** | Instructor performs live, narrating decisions *including wrong paths*; students predict before each step. | L06 spec-reading, L07 strip, L12 printer story, L15 mojibake, L16 zoom, L19 failed lookup, L28 verification |
| **Group discussion** | Stakeholder or position teams; each team must voice its assigned view before verdicts; instructor judges reasoning quality, not position. | L04 debate, L23 gauntlet, L24 CS-02, L26 CS-03 |
| **Scenario-based questions** | Scenario card → written isolation/analysis steps → reveal or swap. Steps must be ordered and falsifiable. | L12 relay, L21 failure annotation, L29 audit |
| **Hands-on activity** | Students on machines/builds; instructor circulates with one circulating question; handout carries the checklist. | L11 reorganize, L18 Lab 5, L19 Lab 6, L26 cleaning |
| **Exit tickets** | Last slide; slips at the door (or LMS). Instructor sorts into got-it / near-miss / lost *same night*; the sort opens the next lecture. | Every lecture |

**Varied-experience adaptations:** mixed-ability pairs for hands-on (stronger partner narrates, weaker types); scenario cards carry a role line so novices have an entry point; extensions (`EXT:`) exist in every deck for fast finishers so they never become co-teachers by accident.

## 3. Instructor presentation checklist (per lecture)

- [ ] Deck read end-to-end once; run sheet times adjusted to this section's reality
- [ ] Resources line at the deck head gathered (props, samples, files, tested URLs)
- [ ] Demonstrations rehearsed on the *lecture-hall* machine (projector + network state)
- [ ] Activity materials counted (cards, slips, worksheets, handouts)
- [ ] Exit-ticket collection plan chosen (paper slips vs LMS) and the next lecture's opening noted
- [ ] Buffer intact in the run sheet — content has not crept into it
- [ ] Module guide's exit-ticket answers at hand for the quick check
- [ ] Planted-error materials (L28 paragraph, L31 bug) verified present — never improvised live

## 4. Accessibility and readability checklist

**Slides themselves:**
- [ ] Contrast pairs meet WCAG AA on the lecture-hall projector (dark theme *off* — dark decks wash out)
- [ ] Minimum body-text size ~24 pt equivalent; no slide over ~35 words
- [ ] Every diagram also stated in words (the deck's TALK covers it; slide keeps the *Figure:* line where used)
- [ ] Decorative content absent; every element earns its place (deck grammar enforces text-light slides)
- [ ] Numbers/statistics only where the lecture page cites a source — decks never add unsourced figures

**Delivery:**
- [ ] Verbalize every diagram ("what this picture shows is…") — screen-reader rule made spoken habit
- [ ] All student-facing handouts follow the site's accessibility standards (alt text, real headings)
- [ ] Pace: one idea per slide, one breath between — the `[~m]` targets encode this
- [ ] Microphone if the hall needs it; face the room, not the screen
- [ ] Activities have a non-visual path (pairs describe rather than point where needed)

**After class:**
- [ ] Slips sorted same night; the next lecture's S1 uses the sort
- [ ] Common misconceptions heard → module guide's misconception section (next revision)
