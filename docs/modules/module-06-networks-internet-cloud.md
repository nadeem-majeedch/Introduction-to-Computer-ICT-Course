# Module 6 — Networks, Internet, and Cloud

> **Lectures:** L21–L24 · **Weeks:** 11–13 · **Stage:** 3 (Build & connect)

## What this module is about

When you press Enter on a URL, a remarkable relay race begins: your device, your router, your ISP, DNS, undersea cables, a data centre, and back — in a fraction of a second. Module 6 follows that race: local networks first, then the internet's machinery, then the web that rides on it, and finally the cloud platforms where modern services live.

## Module learning outcomes

- Classify networks by scale (PAN/LAN/MAN/WAN) and match hardware (switch, router, access point) to roles. (CLO-7)
- Trace a web request end to end: DNS lookup, TCP connection, HTTP request/response, rendering. (CLO-7)
- Explain what HTTPS changes relative to HTTP and why it matters for privacy and integrity. (CLO-7, CLO-10)
- Compare cloud service models and pick the appropriate model for a described scenario. (CLO-7)

## Study advice

Practise narrating the full journey of a web request out loud — L22's role-play makes you do exactly this. It is the single most exam-relevant synthesis in Module 6 and it quietly bundles DNS, IP, TCP, and HTTP into one story.
