# Module 7 — Data, Databases, and Intelligent Systems

> **Lectures:** L25–L28 · **Weeks:** 13–15 · **Stage:** 4 (Evaluate & design)

## What this module is about

Modern computing is dominated by data: collecting it, storing it reliably, analysing it honestly, and — increasingly — letting systems learn from it. Module 7 covers relational databases and information systems, the data-science workflow, how machine learning actually learns, and the judgement needed to use AI responsibly.

## Module learning outcomes

- Explain tables, primary/foreign keys, relationships, and integrity; write elementary SELECT queries. (CLO-8)
- Describe the data-science lifecycle and apply cleaning/visualization principles to a small dataset. (CLO-6, CLO-8)
- Distinguish systems that learn from data from those that follow fixed rules. (CLO-10)
- Critically evaluate AI-generated content and describe fairness and provenance concerns. (CLO-10)
