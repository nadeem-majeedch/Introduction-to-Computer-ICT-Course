# Module 3 — Software and Operating Systems

> **Lectures:** L09–L12 · **Weeks:** 5–7 · **Stage:** 2 (Represent & manipulate)

## What this module is about

Hardware only follows orders. Module 3 is about the orders: the software landscape, how operating systems turn hardware into a usable machine, how file systems organize information, and how to install, update, and troubleshoot software like a professional rather than a victim.

## Lectures

| Lecture | Title | You will learn to |
|---|---|---|
| [L09](../lectures/L09-software-landscape.md) | The Software Landscape | Categorize system vs application software; compare software licensing models |

| [L11](../lectures/L11-file-systems-and-file-management.md) | File Systems and File Management | Master files, folders, paths, formats, and backup discipline |
| [L12](../lectures/L12-installing-updating-troubleshooting.md) | Installing, Updating, and Troubleshooting | Apply a structured troubleshooting method and get help effectively |

## Module learning outcomes

- Classify software into system and application categories with correct edge cases (drivers, firmware, utilities). (CLO-3)
- Describe the OS responsibilities: process management, memory management, and user interface. (CLO-3)
- Navigate and organize a file system using absolute and relative paths; design a sane folder structure. (CLO-3)
- Follow the standard troubleshooting loop and describe safe installation/update practice. (CLO-3)
