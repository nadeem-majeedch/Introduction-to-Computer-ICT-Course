# Module 2 — Hardware: Inside the Machine

> **Lectures:** L05–L08 · **Weeks:** 3–4 · **Stage:** 1 (Describe & identify)

## What this module is about

Module 2 opens the case. We build the mental model every later module refines: the von Neumann architecture — a CPU that executes stored instructions, memory that holds programs and data, and devices that connect the machine to the world. You will finish able to explain what happens in the milliseconds between pressing a key and seeing the character.

## Lectures

| Lecture | Title | You will learn to |

| [L05](../lectures/L05-von-neumann-architecture.md) | The von Neumann Architecture | Explain the stored-program model and the roles of CPU, memory, I/O, and buses |

## Module learning outcomes

- Explain the stored-program concept and why it made modern computing possible. (CLO-2)
- Describe the instruction cycle and the roles of the control unit, ALU, and registers. (CLO-2)
- Arrange the memory hierarchy correctly and justify each level's trade-off. (CLO-2)
- Select storage and peripheral hardware for given requirements and constraints. (CLO-2)
