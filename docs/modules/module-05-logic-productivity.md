# Module 5 — Digital Logic and Productivity Tools

> **Lectures:** L17–L20 · **Weeks:** 9–11 · **Stage:** 3 (Build & connect)

## What this module is about

Module 5 joins two skills that look unrelated but share one idea: systems built from simple, composable parts. Boolean logic composes into gates and the circuits inside every processor; a handful of document, spreadsheet, and presentation techniques compose into professional digital workflows.

## Lectures

| Lecture | Title | You will learn to |
|---|---|---|
| [L17](../lectures/L17-boolean-logic-truth-tables.md) | Boolean Logic and Truth Tables | Build truth tables for AND, OR, NOT, XOR, NAND, NOR from expressions |
| [L18](../lectures/L18-logic-gates-simple-circuits.md) | Logic Gates and Simple Circuits | Predict the behaviour of gate circuits; build a half adder |
| [L19](../lectures/L19-productivity-docs-spreadsheets.md) | Productivity Tools I: Documents and Spreadsheets | Apply styles, formulas, references, core functions, and charts |
| [L20](../lectures/L20-productivity-presentations-workflows.md) | Productivity Tools II: Presentations and Workflows | Design accessible slides and manage versioned, collaborative workflows |

## Module learning outcomes

- Construct truth tables from Boolean expressions and vice versa. (CLO-5)
- Trace signals through combinational circuits including half/full adders. (CLO-5)
- Produce a styled document and a formula-driven spreadsheet with charts meeting stated requirements. (CLO-6)
- Apply slide-design and accessibility principles and use file versioning in team workflows. (CLO-6)
