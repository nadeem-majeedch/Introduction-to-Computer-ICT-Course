## How labs are graded

All labs use the same three criteria (details on each handout):

| Criterion | Weight |
|---|---|
| Correct completion of required tasks | 60% |
| Working demonstration or artifact | 25% |
| Reflection questions answered thoughtfully | 15% |

- **Submission:** as specified per lab (file export, screenshot set, or short write-up) via the course LMS.
- **Late policy:** 10% per day (see [Assessment](../assessment.md#3-labs-20)).
- **Collaboration:** discuss approach freely; execute and submit your own work.

## Lab environment notes

- Any OS works: Windows 10/11, macOS 12+, or a current Linux distribution.
- Spreadsheet labs accept Excel, Google Sheets, or LibreOffice Calc.
- Lab 7 needs a modern browser and a free cloud account (the handout lists acceptable providers and cleanup steps).
- If your machine can't run something, university lab machines satisfy every requirement — see [Help](../help.md#3-getting-help).
- Every handout now carries **expected observations, troubleshooting, and accessibility alternatives**; the workbook page consolidates the safety rules and fallbacks — see [Practical Lab Workbook](workbook.md#accessibility-and-fallbacks).
