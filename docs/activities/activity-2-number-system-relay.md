# A2 — Number System Relay

> **Lecture:** L13 · **Time:** 20 min · **Groups:** two teams of 4–6, lined up in relay order

## Goal

Speed *with* method: conversions done fast but shown properly, mirroring exam marking (method marks).

## Setup

Board/projector shows one conversion at a time. Each team line has one marker. The runner at the board solves *one step* (e.g., one division by 2, one nibble grouping), then passes the marker back. Teams may not shout answers to the board-runner — the work must appear stepwise.

## Rounds

| Round | Task | Value |
|---|---|---|
| 1 | decimal → binary | 45 |
| 2 | binary → decimal | `10110110` |
| 3 | binary → hex | `1110 1001` (group first!) |
| 4 | hex → decimal | `0x1F4` |
| 5 | decimal → hex | 200 |
| 6 (sprint) | 8-bit two's complement of −45 | — |

## Scoring

+2 per correct final answer; +1 per correct intermediate step; −1 for a skipped step that "luckily" lands right (the point of the game: luck isn't method). First correct finish gains +1 bonus.

## Debrief (5 min)

Which steps ate the most time? (Usually: powers of two not memorised; nibble grouping skipped.) Those are the exam time-sinks — Lab 4's sprints target exactly them.

## Solo variant (revision)

Run rounds 1–5 against a 60-second timer each, showing all work. Log your times; re-test after Lab 4.
