## 2. Course description

An introduction to computing for students of all backgrounds: the history and types of computers, hardware architecture, operating systems and files, number systems and data representation, Boolean and digital logic, productivity tools, computer networks, the internet and web, cloud computing, databases and data-science foundations, artificial intelligence with responsible-use literacy, cybersecurity and privacy, computational thinking, and emerging technologies. Weekly labs and a semester-long integrated project develop practical skills alongside conceptual understanding.

## 3. Course learning outcomes (CLOs)

On successful completion, students will be able to:

| CLO | Statement |
|---|---|
| CLO-1 | Describe the historical evolution of computing and classify types of computers by capability and application domain |
| CLO-2 | Explain the von Neumann model and the function of CPU, memory hierarchy, storage, and peripherals |
| CLO-3 | Distinguish system from application software and demonstrate operating-system and file-management operations |
| CLO-4 | Convert numbers among binary, octal, decimal, and hexadecimal and explain how text, images, audio, and video are encoded |
| CLO-5 | Construct truth tables and predict the behaviour of simple combinational circuits built from AND, OR, NOT, XOR, NAND, NOR |
| CLO-6 | Use word-processing, spreadsheet, and presentation tools, including formulas and charts, to complete realistic digital workflows |
| CLO-7 | Explain networking, internet, and web fundamentals (protocols, IP/DNS, HTTP) and the cloud service models IaaS/PaaS/SaaS |
| CLO-8 | Explain relational database concepts (tables, keys, queries, integrity) and demonstrate elementary queries |
| CLO-9 | Apply computational thinking — decomposition, pattern recognition, abstraction, algorithm design — to small problems |
| CLO-10 | Identify common security and privacy threats and apply safe, legal, ethical practices, including critical evaluation of AI-generated output |
| CLO-11 | Synthesize course concepts in an integrated semester project (design document + working artefact + presentation) |

## 4. Teaching and learning methodology

- **Lectures:** concept-first with worked examples; each lecture includes a short in-class activity.
- **Labs:** one graded lab per module, performed individually on your own computer or lab machines.
- **Activities and case studies:** collaborative problem-solving drawn from realistic scenarios.
- **Project:** an integrated semester project assigned in Week 4 (L08), with milestones in Weeks 8 and 12, and a showcase in Week 16 (L32).

## 7. Course policies

- **Attendance:** `[Institution policy]`
- **Late work:** labs lose 10% per day late; the project milestone schedule is firm.
- **Academic integrity:** All submitted work must be your own. Where AI tools are permitted for an assessment, the task sheet states exactly what use is allowed and how it must be disclosed. Undisclosed AI assistance is an integrity violation — see L28 for the reasoning behind this policy.

- **Communication:** announcements happen in class and on the course LMS; this website carries only stable course materials.
- **Accessibility:** students requiring accommodations should contact the instructor and the institutional accessibility office in Week 1; all course materials are prepared to accessibility standards (headings, alt text, captions).
