# Glossary

Every key term used in this course, defined in plain language. Terms are introduced with a bold, in-context definition in their lecture first; this page is the consolidated reference.

---

## A–B

**AI (artificial intelligence)** — Computer systems that perform tasks associated with human intelligence, such as recognizing speech, recommending content, or generating text. See L27.

**Algorithm** — A finite, unambiguous sequence of steps that solves a problem. See L31.

**ALU (arithmetic logic unit)** — The part of the CPU that performs arithmetic and logic operations. See L06.

**Application software** — Programs that help users perform tasks, such as writing documents or editing photos. Compare *system software*. See L09.

**ASCII** — A 7-bit character code standard from the 1960s covering 128 characters used in English. See L15.

**Bandwidth** — The data-carrying capacity of a network link, usually measured in bits per second. See L21.

**Binary** — The base-2 number system using digits 0 and 1; the fundamental representation of data in computers. See L13.

**Bit** — A single binary digit, 0 or 1; the smallest unit of information.

**Boolean logic** — The algebra of true/false values using operations such as AND, OR, NOT. See L17.

**Boot** — The startup sequence that loads the operating system when a computer is switched on. See L10.

**Bus** — A shared set of wires carrying data, addresses, and control signals between CPU, memory, and devices. See L05.

**Byte** — A group of 8 bits; commonly the size of one ASCII character.

## C–D

**Cache** — Small, fast memory close to the CPU that stores recently used data. See L07.

**Character encoding** — A system that assigns numbers to characters so text can be stored as bits (ASCII, UTF-8). See L15.

**Cloud computing** — Delivering compute, storage, and software as on-demand services over the internet. See L24.

**Compiler** — A program that translates human-written source code into machine code (covered conceptually; deep study comes in later courses). See L09.

**Compression** — Representing data with fewer bits; lossless compression preserves everything, lossy compression discards detail humans notice least. See L16.

**CPU (central processing unit)** — The processor that executes program instructions step by step. See L05–L06.

**Database** — An organized collection of data managed for reliable storage and retrieval. See L25.

**Data science** — The practice of extracting knowledge from data using preparation, analysis, and visualization. See L26.

**DNS (domain name system)** — The internet's directory that translates names like `example.edu` into IP addresses. See L22.

**Digital citizen/digital citizenship** — The norms of safe, ethical, responsible participation in digital society. See L30.

## E–H

**Embedded system** — A computer built into another device (car, washing machine, hearing aid) with a dedicated function. See L03.

**Encryption** — Scrambling data so only authorized parties can read it; the basis of HTTPS and device security. See L23, L29.

**Ethernet** — The standard wired local-network technology. See L21.

**File system** — The operating-system structure that organizes files on storage. See L11.

**Firmware** — Software stored on hardware that provides low-level control of a device. See L09.

**Flowchart** — A diagram of an algorithm's steps and decision points using standard shapes. See L31.

**Font** — A styled set of characters used in documents (serif/sans-serif; see L19).

**GPU (graphics processing unit)** — A processor specialized for parallel rendering and computation. See L08.

**GUI (graphical user interface)** — An interface of windows, icons, and menus driven by a pointer/touch. Compare *CLI*. See L10.

**HDD (hard disk drive)** — Storage that reads/writes magnetic platters; larger and slower than SSDs. See L08.

**Hexadecimal** — Base-16 notation (digits 0–9, A–F); a compact way to write binary. See L13.

## I–M

**IaaS / PaaS / SaaS** — Cloud service models: Infrastructure, Platform, and Software as a Service. See L24.

**Instruction cycle** — The fetch–decode–execute loop the CPU repeats for every instruction. See L06.

**IP address** — A numeric address identifying a device on an IP network (IPv4/IPv6). See L22.

**IoT (internet of things)** — Networks of physical devices with embedded sensors/connectivity. See L32.

**Kernel** — The core of an operating system managing hardware resources. See L10.

**Latency** — The delay before data transfer begins; distinct from bandwidth. See L21.

**Lossless/lossy** — See *compression*.

**Malware** — Malicious software, including viruses, worms, ransomware, and spyware. See L29.

**Memory (RAM)** — Fast, temporary working storage for running programs; contents vanish when power is lost. See L07.

**Metadata** — Data about data (file size, author, photo location). See L11.

**MFA (multi-factor authentication)** — Login requiring two or more independent proofs of identity. See L29.

**Mojibake** — Garbled text caused by decoding bytes with the wrong character encoding. See L15.

**Moore's law** — The historical trend of doubling transistor density roughly every two years, named for Gordon Moore; a trend, not a law of physics. See L06.

## N–P

**Network topology** — The arrangement of a network's links and nodes (bus, star, mesh, ring). See L21.

**Operating system (OS)** — The system software managing hardware, programs, and files (Windows, macOS, Linux). See L10.

**Packet** — A small unit of network data with headers; large transfers are split into packets. See L22.

**Peripheral** — Any input, output, or storage device connected to the computer. See L08.

**Pixel** — A single picture element; the smallest controllable dot of a raster image. See L16.

**Protocol** — An agreed set of rules for communication between systems (TCP, IP, HTTP). See L21–L23.

**Phishing** — A social-engineering attack using fake messages/sites to steal credentials. See L29.

**Process** — A running program instance managed by the OS. See L10.

## Q–S

**Query** — A request for data from a database, e.g., a SQL SELECT statement. See L25.

**RAID** — Redundant array of independent disks; techniques combining drives for speed and/or safety. See L08.

**Raster/vector** — Raster images store pixels; vector images store drawing instructions that scale cleanly. See L16.

**Relational database** — A database organizing data into tables related by keys. See L25.

**Resolution** — The number of pixels in an image or display. See L16.

**ROM** — Read-only memory holding start-up firmware; non-volatile. See L07.

**Sample rate** — How many times per second audio is measured, in hertz. See L16.

**SQL (structured query language)** — The standard language for querying relational databases. See L25.

**SSD (solid-state drive)** — Flash-based storage with no moving parts; faster and more shock-resistant than HDDs. See L08.

**Supercomputer** — The fastest class of computers, used for large scientific simulation. See L03.

**System software** — Software that manages the computer itself: operating systems, drivers, utilities. Compare *application software*. See L09.

## T–Z

**TCP/IP** — The core protocol suite of the internet: reliable delivery (TCP) over addressing and routing (IP). See L22.

**Two's complement** — The standard binary representation of negative integers. See L14.

**Unicode** — The universal character standard covering writing systems and symbols. See L15.

**URL** — Uniform resource locator: the address of a web resource. See L23.

**UTF-8** — The dominant Unicode encoding on the web; backward-compatible with ASCII. See L15.

**Virtual memory** — An OS technique extending RAM using disk space. See L07.

**Virtualization** — Running multiple virtual machines on one physical computer. See L24.

**von Neumann architecture** — The stored-program computer model: CPU, memory, I/O, buses; programs stored in the same memory as data. See L05.

**VPN** — Virtual private network; an encrypted tunnel between a device and a network. See L30.

**Wi-Fi** — The family of IEEE 802.11 wireless LAN standards. See L21.

**World Wide Web** — The hypermedia service running over the internet; not the same as the internet itself. See L23.
