# Integrated Project — Rubric

> **Weight:** 25% of course grade · **Milestones:** [milestones.md](milestones.md) · **Brief:** [brief.md](brief.md)

The rubric states exactly how the 25% is earned. Rubric criteria are public; annotated sample responses are not.

---

## Component weights

| Component | Weight (of 25%) |
|---|---|
| Milestone 1 — Proposal | 10% |
| Milestone 2 — Design document | 10% |
| Milestone 3 — Working check | 15% |
| Milestone 4 — Showcase + report | 65% |

## Milestone 4 detail (65% of the 25%)

### A. Artefact quality & integration — 30%

| Criterion | Weight |
|---|---|
| Core mechanism works live (demonstrated, not narrated) | 10% |
| Four-module integration is real and mapped (each module's contribution visible in the artefact) | 10% |
| Correctness of underlying concepts (data representation, formulas/logic, data handling as applicable) | 5% |
| Scope discipline: finished and honest over ambitious and broken | 5% |

### B. Presentation — 20%

| Criterion | Weight |
|---|---|
| Slide standards (one message per slide, contrast, no walls of text — L20) | 5% |
| Accessibility of slides/artefact (alt text, meaningful links, header rows) | 5% |
| Live demonstration competence (runs, handles the unexpected gracefully) | 5% |
| Timing, clarity, equal participation in pairs | 5% |

### C. Final report — 15%

| Criterion | Weight |
|---|---|
| Document craft (styles, TOC, headings — L19 standards) | 5% |
| Design narrative: decisions justified, module map accurate, flowchart updated to reality | 5% |
| Honesty of limitations + integrity disclosure where applicable (L28) | 5% |

## Band descriptors (Milestone 4, artefact component)

| Band | Description |
|---|---|
| Excellent | Demonstrates live without workaround; each of the four modules' contributions is visible in the artefact itself; a visitor could use it unaided. |
| Proficient | Works with minor friction; module map accurate but some contributions thin (mapped but not visibly used); usable with brief guidance. |
| Developing | Core works partially or via setup the audience doesn't see; integration asserted more than shown; guidance needed throughout. |
| Beginning | Not demonstrable live, or fewer than four modules genuinely engaged, or concept errors in the underlying representation/logic. |

## Integrity clause

Any undisclosed AI assistance, or inability to explain your own artefact's parts at the showcase, triggers the [syllabus integrity policy](../../syllabus.md#7-course-policies). Disclosure is cheap; discovery is expensive.
