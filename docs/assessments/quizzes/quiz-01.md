# Practice Q01 — L01–L02 (What Is a Computer? · History)

Answer all five, then expand each for the self-check. These practice items differ from the graded quiz's questions.

## Q1

A vending machine accepts coins, decides what to dispense, and returns change. Using L01's definition, argue whether it is a computer.

<details>
<summary>Self-check</summary>

It satisfies input (coins/keys), processing (a controller chip deciding change), output (dispensing), and storage (prices/menus) — so it contains a computer, but as an **embedded, special-purpose** one: it is *programmable only within one job*, so the machine as a whole is not a general-purpose computer.
</details>

## Q2

Classify: (a) spreadsheet software, (b) the keyboard, (c) your typed essay, (d) you, tired at 2 a.m.

<details>
<summary>Self-check</summary>

(a) software, (b) hardware, (c) data, (d) user. The four-way split from L01 §1.2 — note the essay is *data*, not "information," until something processes/reads it with meaning.
</details>

## Q3

Put in chronological order and give each a one-phrase contribution: transistor, Jacquard loom, ENIAC, stored-program concept, Intel 4004.

<details>
<summary>Self-check</summary>

Jacquard loom (1801, machine programmed by hole patterns) → ENIAC (1945, first general-purpose *electronic* computer) → stored-program concept (1945 EDVAC report; program kept in memory as data) → transistor (late 1940s–50s; reliable small switches) → Intel 4004 (1971; whole CPU on one chip, enabling personal computing).
</details>

## Q4

Why is the stored-program idea more significant than ENIAC being big and fast?

<details>
<summary>Self-check</summary>

ENIAC was fast but *rewiring-defined*: its "program" was its configuration. Storing the program in memory (like data) means machines switch programs by loading files — making software an artefact, an industry, and everything from app stores to your phone possible. It changed the *model*, not the speed.
</details>

## Q5

Name the generation framework's four technology stages in order, and the boundary case: why do some textbooks disagree about where "generations" end?

<details>
<summary>Self-check</summary>

Vacuum tubes → transistors → integrated circuits → microprocessors. The framework is a *teaching summary* of hardware transitions with fuzzy edges (mobile/multi-core/SSD eras don't map cleanly to a "fifth generation"), so textbooks draw boundaries differently — the transitions, not the labels, carry the meaning.
</details>
