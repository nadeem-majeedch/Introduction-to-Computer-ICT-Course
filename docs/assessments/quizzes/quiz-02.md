# Practice Q02 — L03–L04 (Types of Computers · Society and You)

## Q1

Match each job to the class of computer it needs, with a one-clause reason: (a) national weather simulation, (b) decades of bank transaction processing, (c) controlling a car's fuel injectors, (d) this semester's coursework.

<details>
<summary>Self-check</summary>

(a) supercomputer — maximum scientific throughput; (b) mainframe — massive, reliable, long-lived transaction processing; (c) embedded system — dedicated real-time function inside a product; (d) personal computer — general-purpose single-user work.
</details>

## Q2

Why is "a server" a role rather than a kind of machine? Give the two properties that make purpose-built server hardware different anyway.

<details>
<summary>Self-check</summary>

Any computer running server *software* for network clients is serving — the role defines it. Purpose-built server hardware differs by being optimised for uptime (redundant power/disks, remote management) and for many concurrent clients rather than interactive comfort.
</details>

## Q3

A smartwatch and a smartphone both run apps. Why does L03 classify the watch as *closer to embedded*?

<details>
<summary>Self-check</summary>

Classification follows function and constraint: the watch exists inside a product for a constrained set of purposes (fitness, notifications, time) with severe power/size limits; the phone is a general-purpose platform where arbitrary software is the primary value. Degree, not absolute: both are computers.
</details>

## Q5

Apply L04's four-step ethics method to "university proctors online exams with webcam monitoring."

<details>
<summary>Self-check</summary>

Sample structure — stakeholders: students, proctors, institution, accreditation bodies; harms/benefits: integrity assurance vs privacy chilling and surveillance discomfort; proposed rule: monitoring with notice, consent, retention limits, human review of flags; hard case: students without private rooms — does the rule still protect them? </details>
